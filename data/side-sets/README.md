Side sets `𝒮_R` of the `(0,1)` towers (notes/12-three-chains.md, "The closed class of the
`(0,1)` towers"), for `R = □_g`. Each file is one line of `rodf -I 2 -K 6 -Y zmin -Z zmax -p
w,g,g,w,g,g,w,g,g 333`: the heights `z` at which cutting `(2,0)` leaves a two-wide stalk with no
P cut of the poison column above `z`. Runs were stopped early (container restarts, memory), so
each file ends at its last computed `z`; `?z` would mark a certificate that did not close (none
here).
